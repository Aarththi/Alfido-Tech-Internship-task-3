## Objective

To analyze website traffic data using Microsoft Excel and identify visitor trends, user behavior, and business insights.

## Files Included

* Website Traffic Analysis Excel File

## Tools Used

* Microsoft Excel
* Pivot Tables
* Charts
* Data Cleaning
* Data Analysis

* Identified key insights and provided recommendations to improve user engagement.
* Prepared a PDF report with analysis and recommendations.
